# First release preview: desktop demo

This is a first-release preview, not a certified production release or evidence of frontier-model parity.

1. Open **Get Mother** on the preview website and select **Download Mother**. Open the direct Windows EXE, Mac PKG, or Debian/Ubuntu DEB installer and complete the normal operating-system prompts. The consumer flow has no ZIP, source folder, or terminal.
2. Launch Mother. Her included local engine starts automatically. Use the welcome wizard to choose a model that fits the computer and approve its download. Model download progress is real. Availability still needs to be confirmed on the demo computer.
3. In Sanctuary, let the particle body assemble. Drag to rotate it and use Wave. Enable browser/device voice before sending a message if a working voice is available.
4. With a selected, running model, ask a short reasoning or coding question. The model's actual name appears on its response. An Offline guide label means there is no neural response; do not present that as a functioning language model.
5. Open Knowledge, upload a small text file with a fact about your demonstration project, inspect it, and approve it. Ask about that fact. Relevant approved excerpts enter the local reference context. This demonstrates reference memory, not weight training.
6. Open Coding studio and select a disposable demonstration folder. Open a file, edit its proposed contents, review the change, then apply it and restore it. This demonstrates real approved file changes. Do not use investor/customer files without permission.
7. Open Connections → App permissions. Create a scoped demonstration grant and show the compatible-app API example. A grant is not proof that a third-party vendor app is connected. Revoke the grant after demonstrating it.
8. Open Security lab. Hash a local sample file and review a short code sample. Security tool bridge reports installed host tools; it is not the entire Kali suite. Do not run network checks at an event without explicit owner authorization.

Before the event, test the complete flow on the actual computer, finish any model downloads, check audio, and keep a private memory backup. Mother manages the included runtime while her desktop app is open. Desktop packages are unsigned previews. Native platform builds, launch tests, operating-system signing, preview hosting and production release are separate milestones.

Claims supported by this preview: live 3D interface, local-model integration when configured, approved reference memory, reviewed code edits, and scoped app API. Unsupported claims include universal app/IoT control, autonomous neural training, full Kali capability, and matching ChatGPT/Codex/Claude in general performance.
